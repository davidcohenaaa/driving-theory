# אתר תיאוריה לרכב פרטי

אתר סטטי: HTML, CSS ו-JavaScript רגיל, בלי build. כל התוכן יושב בתיקיית `content/` ואפשר לערוך אותו בלי לגעת בקוד.

## הרצה מקומית
הדפים טוענים קבצי JSON, ולכן צריך שרת (פתיחה ישירה של הקובץ לא תעבוד):

```
python3 -m http.server 8000
```
ואז לפתוח `http://localhost:8000`.

## איך עורכים

| רוצים לשנות | עורכים |
|---|---|
| שאלה חדשה או קיימת | `content/questions.json` |
| תמרור (נוצר אוטומטית, ראו להלן) | `content/signs.json` |
| שיעור של נושא | `content/topics/<id>.html` (כל כותרת `<h3>` פותחת שלב חדש בשיעור) |
| רשימת הנושאים | `content/topics.json` |
| שם האתר, מספר שאלות במבחן, זמן, מספר טעויות מותר | `content/site.json` |
| צבעים | משתני `:root` בראש `css/styles.css` |

### מבנה שאלה
```json
{
  "id": "qc200",
  "topic": "basics",
  "question": "טקסט השאלה?",
  "answers": ["תשובה א", "תשובה ב", "תשובה ג", "תשובה ד"],
  "correct": 1,
  "explanation": "הסבר קצר שמופיע אחרי המענה.",
  "group": "concept"
}
```
- `group`: `concept` = שאלות הבנה שמופיעות בבדיקת ההבנה בסוף השיעור; `official` = שאלות מאגר שמופיעות בתרגול ובמבחן.
- `source` (אופציונלי): מקור השאלה, מוצג מתחת לתשובה.
- `correct` הוא המיקום של התשובה הנכונה, מתחיל ב-0 (0 = הראשונה).
- ה-`id` חייב להיות ייחודי, והוא מזהה את השאלה בהתקדמות השמורה.
- תמונה אופציונלית: `"image": "images/qc200.png"` ו-`"imageAlt": "תיאור התמונה"`.

## המסלול ללמידה
לכל נושא: **שיעור** בשלבים, **בדיקת הבנה** של 6 שאלות (עוברים ב-70% ומעלה), ואחריהן **תרגול** ו**מבחן מלא**. נושא מסומן "הושלם" כשהשיעור נקרא ובדיקת ההבנה עברה.

## מקור התוכן
השיעורים (13 פרקים), 101 שאלות ההבנה ו-372 שאלות המאגר יובאו מהעמוד "תיאוריה B" שנבנה קודם. 372 השאלות מסומנות שם כשאלות מאגר החינוך התעבורתי (תשפ"ב, 2022), אך לא נבדקו מול הקובץ הרשמי. 3 שאלות שדורשות תמונה שלא נשמרה הוצאו. חלק מהשיעורים עלולים להכיל אי-דיוקים (למשל כללי הדלקת אורות), ולכן יש לאמת מול מקור רשמי לפני הסתמכות.

## אחוז המוכנות
בדף הראשי מוצג "כמה אתה קרוב לידע". שאלה נחשבת **בשליטה** אם ענית עליה נכון לפחות פעמיים והתשובה האחרונה נכונה. האחוז הוא שאלות בשליטה חלקי כלל השאלות באתר, ולכן הוא יורד אם טועים שוב, ומשקף ידע ולא רק ניסיון. נושא נחשב "הושלם" כששיעורו נקרא ובדיקת ההבנה בו עברה (לא לפי אחוז השליטה). ההתקדמות נשמרת בדפדפן בלבד.

## המשחק
`game.html`: מרוץ של 60 שניות עם 3 חיים ובונוס רצף, במצב "מה פירוש התמרור?" ובמצב שאלות. התשובות במשחק נספרות גם בהתקדמות.

## לוח התמרורים
`content/signs.json` ו-`images/signs/` נוצרו אוטומטית מלוח התמרורים הרשמי של משרד התחבורה (PDF, ספטמבר 2022): 393 תמרורים בעשרה חלקים, כל אחד עם מספר רשמי, תמונה, פירוש ותוקף.

כדי לייצר אותם מחדש (למשל כשמתפרסם עדכון):
```
pip install pymupdf
python3 scripts/extract_signs.py <נתיב-ל-PDF>
```
הסקריפט כותב מחדש את `content/signs.json` ואת התמונות. אפשר גם לערוך ידנית פירוש או כותרת ב-`signs.json`, אבל עריכה ידנית תידרס בהרצה חוזרת של הסקריפט.

כל תמרור: `number` (המספר הרשמי), `part` ו-`category` (חלק בלוח), `meaning` (פירוש), `validity` ("כוחו יפה"), `images` (תמונה אחת או יותר).

## מבחן תמרורים
`signs-quiz.html`: מבחן נפרד על כל לוח התמרורים (393 תמרורים), או על חלק אחד בו (אפשר לקשר ישר עם `signs-quiz.html?part=3`). בוחרים חלק, מספר שאלות (10, 20, 30 או כל החלק) וסוג שאלה: רואים תמרור ובוחרים פירוש, רואים פירוש ובוחרים תמרור (רק לתמרורים שהפירוש שלהם ייחודי, כדי שלא תהיה יותר מתשובה נכונה אחת), או מעורב.
- המבחן משתמש ב-`title` של כל תמרור כתשובה קצרה, ובפירוש המלא כהסבר אחרי המענה.
- מותרות טעויות באותו יחס של המבחן המלא: `maxMistakes` מתוך `exam.questions` ב-`content/site.json`, מעוגל כלפי מטה.
- כל תשובה נספרת בהתקדמות התמרורים, כמו במשחק ובלוח התמרורים.
- בסוף המבחן מוצגים התמרורים שטעית בהם, אפשר לתרגל רק אותם.
- בחלק מהכותרות ב-`signs.json` הסוגריים יצאו הפוכים מהחילוץ ("מעבר עילי)עם מדרגות("). המבחן מתקן אותם בתצוגה בלבד.

## בדיקת תקינות לפני פרסום
```
node scripts/validate.mjs
```
הסקריפט מוודא שלכל שאלה יש נושא קיים, תשובה נכונה תקינה ו-id ייחודי, ושקבצי התמונות קיימים.

## פרסום
GitHub Pages: Settings, ואז Pages, ואז לבחור את הענף הראשי ואת התיקייה הראשית.

## חשוב
התמרורים לקוחים מהלוח הרשמי. שאלות התרגול הן עדיין 6 שאלות טיוטה לדוגמה, ולפני פרסום יש להחליף אותן במאגר השאלות הרשמי של משרד התחבורה.
